# 🍂 Portfólio — Anna Rísnia

Site de portfólio pessoal desenvolvido do zero com HTML, CSS e JavaScript puro, hospedado no GitHub Pages.

🔗 **Acesse:** [annarisnia.github.io/portfolio-anna-risnia](https://annarisnia.github.io/portfolio-anna-risnia)

---

## 🖥️ Visão Geral

Site responsivo com design elegante em tons terrosos, apresentando minha trajetória, habilidades e projetos na área de Tecnologia e Segurança Cibernética.

---

## 📌 Seções

- **Início** — Apresentação com foto e links rápidos
- **Sobre mim** — Trajetória, formação e objetivos
- **Habilidades** — Tecnologias e ferramentas dominadas
- **Projetos** — Projetos em destaque com links para o GitHub
- **Contato** — Formas de entrar em contato

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (variáveis, grid, flexbox, responsividade)
- JavaScript (menu hamburguer, scroll suave)
- Google Fonts (Playfair Display + Inter)
- GitHub Pages (hospedagem)

---

## 📁 Estrutura do Projeto

```
📦 portfolio-anna-risnia
```
